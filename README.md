Entry for [One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc) — a program that writes one office joke to `/output/entry.txt`.

> I replied-all asking to be removed from the thread, and now the thread is forty people replying-all to ask to be removed from the thread.

One line, one real office detail, and the laugh lands on the last few words — the thread itself becomes the joke.

## Run

```sh
node main.ts
cat /output/entry.txt
```
